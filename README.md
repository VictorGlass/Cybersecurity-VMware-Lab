# 🛡️ Laboratorio Práctico de Ciberseguridad en VMware

¡Bienvenido a mi repositorio de prácticas de ciberseguridad! Este espacio documenta el avance, resolución de laboratorios, *scripting* y análisis técnico desarrollados dentro de un entorno controlado en **VMware**.

---

## 🖥️ Arquitectura del Laboratorio

El entorno está compuesto por tres máquinas virtuales alojadas en disco local:
* **Atacante:** Kali Linux
* **Servidor / Víctima 1:** Ubuntu Server
* **Víctima Vulnerable 2:** Metasploitable 2
